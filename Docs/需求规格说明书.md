# 智能医院设备管理系统
# 需求规格说明书 (v2.0)

## 1. 系统概述

本系统是一套基于 C# WinForm + .NET 4.7.2 + SQL Server 2017+ 的医院设备全生命周期管理平台。
通过 **设备台账、入库管理、维修管理、借用管理、仪表盘监控、系统设置** 六大模块，
覆盖设备的入、用、修、借、报、查全流程。

### 角色定义

| 角色 | 描述 | 权限范围 |
|------|------|---------|
| 管理员 (admin) | 设备科人员 | 全部功能 |
| 医护 (doctor) | 科室人员 | 查看设备、申请借用、申报故障 |
| 维修员 (repair) | 维修工程师 | 接收工单、维修处理、填写结果 |

## 4. 流程与状态流转

### 维修工单
[医护申报] -> [待分配] -> [已指派] -> [处理中] -> [验收] -> [已完成]
                                                   -> [退回处理中]

### 借用流程
[医护申请] -> [待审批] -> [已批准] -> 设备标记借用中 -> [归还] -> 设备恢复可用
                      -> [已驳回]

### 入库审核
[待审核] -> [审核中] -> [已通过] -> 设备自动入库
                    -> [已驳回]

## 5. 状态枚举

| 分类 | 值 | 说明 |
|------|------|------|
| 设备状态 | InUse/Idle/Borrowed/Maintenance/Scrapped | 使用中/空闲/借用中/维修中/已报废 |
| 维修进度 | Pending/Assigned/InProgress/Review/Done | 待分配/已指派/处理中/验收/完成 |
| 紧急程度 | Low/Normal/Urgent/Emergency | 低/普通/紧急/特急 |
| 借用状态 | Pending/Approved/Rejected/Returned | 待审批/已批准/已驳回/已归还 |
| 入库审核 | Pending/Approved/Rejected | 待审核/已通过/已驳回 |
